# final-project-mobile-media-development
I made newer version of pong. It features 5 levels with each level up progressively getting harder. As you level up the paddle the user has gets smaller with it being the smallest on level 5. The speed of the ball also progressively gets faster as well as how fast the ai reacts to the ball. The user also has 3 power ups in which they can use to beat the AI. Throughout the time that I was developing the app, I was able to use AI to help me with troubleshooting with any of the errors I would get whether that be because of the version of Xcode I was on or I was just inputting something wrong.
